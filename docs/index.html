The productO produto

Zayuni runs the day of a practice.O Zayuni organiza o dia de um consultório.

Independent health professionals often manage appointments in a notebook, patients in a spreadsheet and payments over WhatsApp. Zayuni puts scheduling, patient records, care history and finances in one app that works on phone, tablet and desktop.Profissionais de saúde autônomos costumam controlar a agenda num caderno, os pacientes numa planilha e os pagamentos pelo WhatsApp. O Zayuni reúne agenda, pacientes, histórico de atendimentos e financeiro num app que funciona no celular, no tablet e no computador.

  • Every row is scoped to its account with PostgreSQL row-level security.Cada registro fica restrito à sua conta por row-level security no PostgreSQL.
  • Appointments sync to Google Calendar and iCloud (CalDAV), with provider credentials encrypted at rest.Agendamentos sincronizados com Google Calendar e iCloud (CalDAV), com credenciais dos provedores criptografadas.
  • Pix charges generated as BR Codes, and payment receipts read by OCR on the device. The receipt never leaves the phone.Cobranças Pix geradas como BR Code, e comprovantes lidos por OCR no próprio aparelho. O comprovante nunca sai do celular.
  • Merging to main deploys to staging. Production is a separate, explicit promotion.Merge na main publica em staging. Produção é uma promoção separada e explícita.

The riskO risco

An agent with a shell and a token is a liability.Um agente com shell e token é um risco.

AI agents let a small team move fast. The usual setup gives them a terminal and a GitHub token in the same box. With health data involved, that is not acceptable.Agentes de IA permitem que uma equipe pequena avance rápido. A configuração comum dá a eles um terminal e um token do GitHub no mesmo ambiente. Com dados de saúde envolvidos, isso não é aceitável.

  • A prompt injection can leak the token or push anywhere, including main.Um prompt injection pode vazar o token ou fazer push em qualquer lugar, inclusive na main.
  • The model can report "tests pass" without running anything.O modelo pode dizer que "os testes passam" sem rodar nada.
  • Sending every task to the most expensive model burns money on work that needs no model.Mandar toda tarefa para o modelo mais caro gasta dinheiro em trabalho que nem precisa de modelo.

So I split the problem in two: where agents work, and how their tasks run.Então dividi o problema em dois: onde os agentes trabalham e como as tarefas são executadas.

Where agents work · MCPOnde os agentes trabalham · MCP

ChatGPT and Claude get a workspace with nothing to steal.ChatGPT e Claude recebem um workspace sem nada a roubar.

Agents connect through the Model Context Protocol to an isolated development container. The container is treated as already compromised, so it holds no credentials and its outbound traffic is controlled.Os agentes se conectam pelo Model Context Protocol a um contêiner de desenvolvimento isolado. O contêiner é tratado como já comprometido: não guarda credenciais, e o tráfego de saída é controlado.

  • Cloudflare Access Managed OAuth signs the user in. The origin verifies the JWT on every /mcp request: RS256 only, exact issuer and audience, at most 60 s of clock skew.O login é feito pelo Cloudflare Access Managed OAuth. A origem verifica o JWT em toda requisição /mcp: apenas RS256, issuer e audience exatos, no máximo 60 s de diferença de relógio.
  • When keys are unavailable, the verifier refuses. It fails closed.Se as chaves não estiverem disponíveis, o verificador recusa. Ele falha fechado.
  • Cookies, Authorization and Cf-Access-* headers are stripped before anything reaches the workspace.Cookies e cabeçalhos Authorization e Cf-Access-* são removidos antes de chegar ao workspace.

What leaves the boxO que sai do ambiente

Every push is inspected. Every action is on the record.Todo push é inspecionado. Toda ação fica registrada.

The only route from the workspace to GitHub is a Git gateway I wrote with the Python standard library only. The GitHub token lives there and nowhere else.O único caminho do workspace até o GitHub é um gateway Git que escrevi só com a biblioteca padrão do Python. O token do GitHub fica ali e em nenhum outro lugar.

  • Each pushed pack is indexed in quarantine with git index-pack --strict, checked for fast-forward, and every changed path is compared against protected paths before it is forwarded.Cada pacote enviado é indexado em quarentena com git index-pack --strict, verificado como fast-forward, e cada caminho alterado é comparado com os caminhos protegidos antes do encaminhamento.
  • The audit log stores a closed, content-free schema, chained with HMAC. The kernel verifies each producer's identity (SO_PEERCRED).O log de auditoria guarda um esquema fechado e sem conteúdo, encadeado por HMAC. O kernel verifica a identidade de cada produtor (SO_PEERCRED).
  • If the audit log does not acknowledge an event, the action does not happen.Se o log de auditoria não confirmar o evento, a ação não acontece.

How tasks run · DevCoreComo as tarefas rodam · DevCore

The model reasons. Deterministic code executes and checks.O modelo raciocina. Código determinístico executa e verifica.

DevCore is the engine I built to run coding tasks. The model only proposes actions through a small set of allowed tools. A router decides, per task, the cheapest route that can do the job.O DevCore é o motor que construí para executar tarefas de código. O modelo só propõe ações por um conjunto pequeno de ferramentas permitidas. Um roteador decide, por tarefa, a rota mais barata capaz de resolvê-la.

  • Routes: no model, a local model (Ollama-compatible), a stronger model, or a human. Protected operations always go to a human.Rotas: sem modelo, modelo local (compatível com Ollama), modelo mais forte ou humano. Operações protegidas sempre vão para um humano.
  • Each task gets its own worktree from a base verified against GitHub. Checks run in a separate Docker runner against the modified code.Cada tarefa recebe sua própria worktree a partir de uma base verificada no GitHub. As verificações rodam num executor Docker separado, sobre o código modificado.
  • One task ends as one pull request, and the engine stops there. No merge, no deploy.Uma tarefa termina em um pull request, e o motor para ali. Sem merge, sem deploy.
  • Routing changes are replayed offline against recorded telemetry before they are adopted.Mudanças de roteamento são testadas offline contra a telemetria registrada antes de serem adotadas.
