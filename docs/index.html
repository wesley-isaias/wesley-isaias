O Zayuni é o produto que fundei, usado por profissionais reais. The productO produto

Zayuni runs the day of a practice.O Zayuni organiza o dia de um consultório.

Independent health professionals often manage appointments in a notebook, patients in a spreadsheet and payments over WhatsApp. Zayuni puts scheduling, patient records, care history and finances in one app that works on phone, tablet and desktop.Profissionais de saúde autônomos costumam controlar a agenda num caderno, os pacientes numa planilha e os pagamentos pelo WhatsApp. O Zayuni reúne agenda, pacientes, histórico de atendimentos e financeiro num app que funciona no celular, no tablet e no computador.

  • Every row is scoped to its account with PostgreSQL row-level security.Cada registro fica restrito à sua conta por row-level security no PostgreSQL.
  • Appointments sync to Google Calendar and iCloud (CalDAV), with provider credentials encrypted at rest.Agendamentos sincronizados com Google Calendar e iCloud (CalDAV), com credenciais dos provedores criptografadas.
  • Pix charges generated as BR Codes, and payment receipts read by OCR on the device. The receipt never leaves the phone.Cobranças Pix geradas como BR Code, e comprovantes lidos por OCR no próprio aparelho. O comprovante nunca sai do celular.
  • Merging to main deploys to staging. Production is a separate, explicit promotion.Merge na main publica em staging. Produção é uma promoção separada e explícita.

The riskO risco

An agent with a shell and a token is a liability.Um agente com shell e token é um risco.

AI agents let a small team move fast. The usual setup gives them a terminal and a GitHub token in the same box. With health data involved, that is not acceptable.Agentes de IA permitem que uma equipe pequena avance rápido. A configuração comum dá a eles um terminal e um token do GitHub no mesmo ambiente. Com dados de saúde envolvidos, isso não é aceitável.

  • A prompt injection can leak the token or push anywhere, including main.Um prompt injection pode vazar o token ou fazer push em qualquer lugar, inclusive na main.
  • The model can report "tests pass" without running anything.O modelo pode dizer que "os testes passam" sem rodar nada.
  • Sending every task to the most expensive model burns money on work that needs no model.Mandar toda tarefa para o modelo mais caro gasta dinheiro em trabalho que nem precisa de modelo.

So I built the infrastructure that takes away what agents should never hold, and every change follows the same path to production.Por isso construí a infraestrutura que tira dos agentes o que eles nunca deveriam ter, e toda mudança segue o mesmo caminho até a produção.

In daily use since November 2026. Milestone: from ChatGPT on my phone, with my computer off, an agent created a branch, pushed and opened a pull request.Em uso diário desde novembro de 2026. Marco: pelo ChatGPT no celular, com o computador desligado, um agente criou um branch, fez push e abriu um pull request.

I built my own MCP server: seven Docker services on a VPS. ChatGPT and Claude connect through the Model Context Protocol to an isolated development container. The container is treated as already compromised, so it holds no credentials and cannot reach the server's internal network.Construí meu próprio servidor MCP: sete serviços Docker numa VPS. O ChatGPT e o Claude se conectam pelo Model Context Protocol a um contêiner de desenvolvimento isolado. O contêiner é tratado como já comprometido: não guarda credenciais e não alcança a rede interna do servidor.

  • Cloudflare Access Managed OAuth signs me in, with TOTP MFA. The origin verifies the JWT on every /mcp request: RS256 only, exact issuer and audience, at most 60 s of clock skew.O login é feito pelo Cloudflare Access Managed OAuth, com MFA por TOTP. A origem verifica o JWT em toda requisição /mcp: apenas RS256, issuer e audience exatos, no máximo 60 s de diferença de relógio.
  • When keys are unavailable, the verifier refuses. It fails closed.Se as chaves não estiverem disponíveis, o verificador recusa. Ele falha fechado.
  • Cookies, Authorization and Cf-Access-* headers are stripped before anything reaches the workspace.Cookies e cabeçalhos Authorization e Cf-Access-* são removidos antes de chegar ao workspace.

What leaves the boxO que sai do ambiente

Every push is inspected. Every action is on the record.Todo push é inspecionado. Toda ação fica registrada.

The only route to GitHub is a Git gateway I wrote with the Python standard library only. The GitHub token lives there and nowhere else, and only three repositories are allowed.O único caminho até o GitHub é um gateway Git que escrevi só com a biblioteca padrão do Python. O token do GitHub fica ali e em nenhum outro lugar, e só três repositórios são permitidos.

  • Each pushed pack is indexed in quarantine with git index-pack --strict and checked for fast-forward. Pushes to main and changes under .github/ are refused, and so is merge.Cada pacote enviado é indexado em quarentena com git index-pack --strict e verificado como fast-forward. Push na main e mudanças em .github/ são recusados, assim como merge.
  • The audit log stores a closed, content-free schema, chained with HMAC, and exports checkpoints to a write-locked R2 bucket. The kernel verifies each producer's identity (SO_PEERCRED).O log de auditoria guarda um esquema fechado e sem conteúdo, encadeado por HMAC, e exporta checkpoints para um bucket R2 travado contra alteração. O kernel verifica a identidade de cada produtor (SO_PEERCRED).
  • If the audit log does not acknowledge an event, the action does not happen.Se o log de auditoria não confirmar o evento, a ação não acontece.

How every change shipsComo cada mudança é entregue

Agents propose. Tests, review and a person decide.Agentes propõem. Testes, revisão e uma pessoa decidem.

I write the code with Claude, ChatGPT and other coding agents. What makes that safe is the path every change takes, whoever wrote it.Escrevo o código com Claude, ChatGPT e outros agentes de código. O que torna isso seguro é o caminho que toda mudança percorre, não importa quem a escreveu.

  • Work starts from an approved issue, on its own branch. Nothing is developed on main.O trabalho começa de uma issue aprovada, em branch próprio. Nada é desenvolvido na main.
  • CI runs lint, type checks, the web build and the backend suite. Dedicated regression workflows guard agenda time zones, finance receipts and patient search.A CI roda lint, checagem de tipos, build web e a suíte do backend. Workflows de regressão dedicados protegem fuso horário da agenda, comprovantes do financeiro e busca de pacientes.
  • Merging deploys to staging. Production is a separate promotion that I approve explicitly.O merge publica em staging. Produção é uma promoção separada, que eu aprovo explicitamente.
  • Migrations must be additive and backward compatible, because production holds real data.Migrações precisam ser aditivas e compatíveis com a versão anterior, porque a produção tem dados reais.

Lab: I also prototyped DevCore, an engine that routes coding tasks between local models, stronger models and people, and validates each change in an isolated runner (141 tests). It is an experiment, not part of the production workflow.Laboratório: também prototipei o DevCore, um motor que roteia tarefas de código entre modelos locais, modelos mais fortes e pessoas, e valida cada mudança num executor isolado (141 testes). É um experimento, não faz parte do fluxo de produção.
